# Google Drive Clone

A modern Google Drive clone leveraging:

## Core Technologies

- Next.js 15.1.6 (App Router)
- React 19
- TypeScript
- TailwindCSS
- shadcn/ui components

## Key Features

- Server Actions with Next.js 15's enhanced performance
- Parallel routes and intercepting routes
- Partial prerendering (Next.js 15's new feature)
- File management system
- Real-time updates
- Responsive design

## Backend & Infrastructure

- Database: PostgreSQL with Drizzle ORM
- Authentication: Clerk
- File Storage: UploadThing
- Type-safe database queries with Neon PostgreSQL

## Features

- File upload/download
- Folder organization
- File sharing
- Search functionality
- User management
- Real-time collaboration
